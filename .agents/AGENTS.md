# Project Rules

## Auto Git Push
After making any code changes to files in this project, always commit and push them to the git remote automatically. Follow these steps:
1. Stage all changed files: `git add -A`
2. Commit with a concise, descriptive message summarizing what changed: `git commit -m "<message>"`
3. Push to the remote: `git push origin main`

Do this at the end of every task or set of changes without asking the user.
